# Terminal

The window has a terminal dock: shell tabs, Claude Code tabs, Codex and Cursor tabs when the engine finds those programs, and a Chat tab, with an ask bar at its foot. It sits at the bottom of the window or in a column at the right (the side button in its head switches; side, size and open state are remembered). The engine owns every process; the window draws output and sends keys. The dock is the family's shared module, at 2.0.1 here.

## Rules

- Process control belongs to the engine or the Tauri shell, never to page code; the page reaches the engine only through `frontend/src/io/api.ts`.
- A terminal is remote code execution, so every route and socket passes `origin_ok`, and only the formvis window gets in: opening, resizing, restarting and closing a terminal need the window key in `X-Formvis-Window-Key` (403 "Only the formvis window can do this" without it), and the terminal, Claude Code and agent sockets must send `{"type": "key", "key": ...}` as their first message (`backend/app/core/window_key.py`). An agent's permission request is never answered for the person.
- Terminal output is appended to xterm's own nodes, never rebuilt, and xterm's scrollbar elements are hidden by `terminal.css` (the global sheet does not name them).
- Every child ends when its tab closes, the window goes away or the engine exits.
- Keys typed in the dock, its dialog or its guide stay there: B in a terminal does not pick the Brush. Only the dock's chord (Ctrl+J, Cmd+J on a Mac) and the keys the adapter's `passKey` names leave it.

## The question an outside agent's request raises

- With Outside agents on Ask, a request from an outside agent opens one dialog in the middle of the window: "Allow an agent calling itself NAME to make changes in formvis?", what it asked to do, and Deny, Allow once and Always allow any agent named NAME. Several waiting requests are shown one at a time ("Request 1 of 2").
- An answer covers only the request shown. Allow once runs that one call and the next call asks again. Deny refuses it, and formvis then refuses that agent for ten minutes without asking; other agents are still asked. Escape is Deny.
- Always allow is kept for that one agent name (its policy becomes Allow in Agent Connect); another name is still asked. The name is the agent's own claim: any program on this computer can give any name, so a standing yes is a yes to everything that calls itself that.
- A request can be withdrawn: when the caller hangs up or the question times out (three minutes), the dialog closes unanswered and nothing runs. After a reload the window shows the questions still waiting.
- Blocked is held by the engine, not by the page: it refuses outside agents and the tool calls of formvis's own Claude Code tabs and Chat at once, with or without a window, and stays after a restart. A plain shell tab still opens; it is the person's own.
- The choice is under Preferences > Plugins, Outside agents (Ask, Allowed, Blocked), also reached from the dock's menu; only the window can change it.
