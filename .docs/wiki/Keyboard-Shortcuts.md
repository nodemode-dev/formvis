# Keyboard Shortcuts

Mod is Command on macOS and Ctrl elsewhere. Help, Keyboard Shortcuts shows the same list inside the app.

| Action | Keys |
| --- | --- |
| New canvas | Mod+Alt+N (Mod+N in the desktop app) |
| Open project, Import images | Mod+O, Mod+Shift+O |
| Save, Save As, Save a Copy | Mod+S, Mod+Shift+S, Alt+Mod+S |
| Revert | F12 (desktop app; browsers keep F12) |
| Export PNG | Mod+Shift+E |
| Close tab | Mod+Alt+W (Mod+W in the desktop app) |
| Close All, Close Others | Alt+Mod+W in the desktop app, Alt+Mod+P |
| Undo, Redo | Mod+Z, Mod+Shift+Z or Mod+Y |
| Toggle Last State | Alt+Mod+Z |
| Paste in Place, Paste Into | Shift+Mod+V, Alt+Shift+Mod+V |
| Fill with foreground, background | Alt+Backspace, Mod+Backspace |
| Delete (clears the selection, or deletes the layer) | Backspace or Delete |
| Invert | Mod+I |
| Cut, Copy, Copy Merged, Paste | Mod+X, Mod+C, Mod+Shift+C, Mod+V |
| Levels, Curves, Hue/Saturation | Mod+L, Mod+M, Mod+U |
| Canvas Size, Image Size | Mod+Alt+C, Mod+Alt+I |
| New layer, Duplicate | Mod+Shift+N, Mod+J |
| Group, Move out of folder | Mod+G, Mod+Shift+G |
| Clipping mask, Merge | Mod+Alt+G, Mod+E |
| Bring forward, Send backward | Mod+], Mod+[ |
| Next and previous blend mode | Shift+=, Shift+- |
| Select all, Deselect, Inverse | Mod+A, Mod+D, Mod+Shift+I |
| Feather Selection | Shift+F6 |
| Fill dialog | Shift+F5 |
| Export As | Alt+Shift+Mod+W |
| Show or hide rulers | Mod+R |
| Show or hide guides | Mod+; |
| Lock or unlock guides | Alt+Mod+; |
| Show or hide the grid | Mod+' |
| Liquify | Shift+Mod+X |
| Select and Mask | Alt+Mod+R |
| Zoom in, out, fit, actual pixels | Mod+=, Mod+-, Mod+0, Mod+1 |
| Settings, Shortcuts | Mod+,, Shift+/ |
| Search commands and tools | Mod+K |
| Tools | V Move, M Marquee, L Lasso, W Magic Wand, C Crop, B Brush, E Eraser, J Spot Healing, S Clone Stamp, R Smear, G Gradient, U Shape, I Eyedropper, H Hand, Z Zoom |
| Tool variants | Shift+M marquee shape, Shift+L lasso mode, Shift+U shape kind, Alt-click sets the Clone Stamp source |
| Content-Aware Fill | Shift+Backspace |
| Selection tools (Marquee, Lasso, Magic Wand) | arrows nudge the selection outline 1 px, Shift+arrows 10 px |
| Layers panel | Option-click a row's lower edge clips it to the layer below (again releases); Option-drag a row duplicates it; Option-drag a mask thumbnail onto a layer copies the mask |
| Transform Selection or Layer | Alt+Mod+T (browsers keep Mod+T for a new tab), Mod+T on the desktop; Enter applies a floating selection, Escape cancels |
| Transform Again, and again on a copy | Shift+Mod+T (on the desktop; browsers keep it for reopening a tab), Alt+Shift+Mod+T |
| Auto Tone, Auto Contrast, Auto Color, Desaturate | Shift+Mod+L, Alt+Shift+Mod+L, Shift+Mod+B, Shift+Mod+U |
| Crop and Gradient | Enter applies, Escape cancels |
| Colors | X swap, D default |
| Brush | [ and ] size, Shift+[ and ] hardness, 1 to 0 opacity |
| Move tool | arrows nudge 1 px, Shift+arrows 10 px, 1 to 0 layer opacity, drag inside a selection moves its pixels, Alt+drag duplicates them, Escape cancels |
| Pan | hold Space |
